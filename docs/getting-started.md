# Getting started with Codex CLI

For an overview of Codex CLI features, see [this documentation](https://developers.openai.com/codex/cli/features#running-in-interactive-mode).

Before the first run, authenticate with `bcodex login`. Remote and headless
machines can use `bcodex login --device-auth`; see
[Authentication](authentication.md) for the complete bettercodex flow.
